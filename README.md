# Jatin & Akansha — Friends Wedding Invitation

## Publish on GitHub Pages
1. Create a new public GitHub repository.
2. Upload the **contents** of this folder (not the enclosing folder) to the repository root.
3. Open **Settings → Pages → Build and deployment → Deploy from a branch** and select `main` and `/ (root)`.
4. Wait for the published link and open it on mobile.

## Music
The website supports optional background music. Add a file named `song.mp3` inside `assets/music/`. Use music you have permission to distribute. Music can begin after a guest clicks **Open our story**, because browsers block unprompted autoplay. Without a song, the website works normally.

## Events
The four event cards and map links are in `index.html`. Times are India Standard Time. The countdown targets 26 November 2026, 7:00 PM IST.

## Images
Eight selected 3D animated illustrations are compressed to WebP for faster loading. The generated hands image is intentionally excluded.

## Notes
The story text is a light narrative draft based on Class 6 and a long-distance chapter; review it before sending to guests. No RSVP or family details are included.

## Updating illustrated images
Replace the WebP files inside assets/images/ using the same filenames. Re-upload the changed files to GitHub. Prefer clean source artwork and export to WebP at good quality; do not change HTML image paths.
